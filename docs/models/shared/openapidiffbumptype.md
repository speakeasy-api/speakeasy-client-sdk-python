# OpenapiDiffBumpType

Bump type of the lock file (calculated semver delta, or a custom change (manual release))

## Example Usage

```python
from speakeasy_client_sdk_python.models.shared import OpenapiDiffBumpType

value = OpenapiDiffBumpType.MAJOR
```


## Values

| Name    | Value   |
| ------- | ------- |
| `MAJOR` | major   |
| `MINOR` | minor   |
| `PATCH` | patch   |
| `NONE`  | none    |
